# NexPilot Private Beta Tester Terms

This private beta is non-transferable.

By receiving a tester package or private repository invite, the tester agrees:

- Do not copy, redistribute, mirror, sell, sublicense, publish, or upload this
  source code or package anywhere else.
- Do not invite another person into the repository without Rain's written
  approval.
- Do not share the generated token URL. The token URL grants shell access while
  the agent is running.
- Do not expose the agent to the public internet, router port forwarding, or an
  unapproved relay.
- Use it only on the tester's own computer, on same Wi-Fi/LAN or the tester's
  own Tailscale tailnet.
- Delete the package and repository clone when beta access is revoked.

Technical boundary: source access cannot technically prevent copying by a
recipient. The controls here reduce risk through private access, legal terms,
per-tester package identifiers, checksums, and review gates. Stronger copy
resistance requires a later binary-only build plus license server.
